## EX.-No.3.2.-CREATE-3D-MODEL-FROM-ORTHOGRAPHIC-PROJECTION
## DATE:02-11-2026
## AIM:
To create a 3D model from given orthographic projection.

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
1. Open AutoCAD.
2. Create a new drawing.
3. Set the units to millimetres using UNITS.
4. Select Decimal as the unit type.
5. Set the drawing limits according to the drawing sheet.
6. Turn ON Object Snap (OSNAP).
## DRAW THE FRONT VIEW:
1. Draw a horizontal reference line using LINE.
2. Mark the overall width of 
3. Draw the two horizontal mounting portions.
4. Maintain the specified height
5. Draw the central curved portion using the ARC command.
6. Apply the radius 
7. Trim unwanted lines using TRIM.
8. Draw the centre lines using CENTERLINE.
9. Check the symmetry and alignment of the curved portion.
## DRAW THE TOP VIEW:
1. Project vertical construction lines from the front view.
2. Draw the central rectangular portion.
3. Mark the distance between the two mounting hole centres.
4. Draw the end mounting plates.
5. Use the CIRCLE command to create the mounting holes.
6. Draw the central hole.
7. Apply the curved end profile.
8. Use TRIM to remove unwanted portions.
9. Draw hidden edges using dashed lines.
10. Add centre lines to all circular holes.
## DRAW THE SIDE VIEW:
1. Project horizontal and vertical construction lines from the top and front views.
2. Draw the side profile.
3. Maintain the dimension shown in the drawing.
4. Draw visible edges using continuous lines.
5. Draw hidden edges using dashed lines.
6. Complete the side view using TRIM and EXTEND.
## CREATE THE ISOMETRIC VIEW:
1. Use the front view as the reference.
2. Create the curved central portion.
3. Construct the two vertical mounting plates at both ends.
4. Join the mounting plates to the curved central body.
5. Create the circular holes on both mounting plates.
6. Check the alignment of both end plates.
7. Use the 3DORBIT command to inspect the model.
8. Apply the isometric visual style.
9. Check that the isometric model matches the orthographic views.
7. Apply dimensions
## APPLY LINE TYPES AND FINISHING:
1. Use continuous lines for visible edges.
2. Use dashed lines for hidden edges.
3. Use centre lines for holes and symmetrical features.
4. Adjust line thickness.
5. Arrange all views properly.
6. Check that dimensions are readable.
7. Remove unnecessary construction lines.
## SAVE AND PRINT THE DRAWING:
1. Save the completed drawing using CTRL + S.
2. Open the Plot command using CTRL + P.
3. Select the required sheet size.
4. Set the plot scale.
5. Select monochrome plotting.
6. Preview the drawing.
7. Export the final drawing as a PDF.
